## 🚀 Despliegue en GitHub Pages o Vercel

1. Crea un repositorio llamado `portfolio` en tu cuenta `manchento2`.
2. Vincula el repositorio local y sube los archivos:
   ```bash

   git branch -M main
   git push -u origin main
   ```

2. Selecciona el proyecto y despliega sin necesidad de configuraciones adicionales.
